# Getting Started - SciOS-NG

## 📖 Introduction
Chào mừng bạn đến với **SciOS-NG** – một cognitive operating system thế hệ mới.  
Hướng dẫn này sẽ giúp bạn khởi động nhanh chóng với pipeline reasoning, API, và CLI.

---

## 🛠️ Prerequisites
- **Git** để clone repository.  
- **Docker** hoặc **Kubernetes** để chạy runtime.  
- **Python 3.10+** hoặc **Node.js 18+** để dùng SDK.  
- Quyền truy cập vào **SciOS-NG Kernel API**.
