# SciOS Research Repository

This repository hosts research projects, manuscripts, datasets, and benchmarks developed under the SciOS initiative.  
It provides a structured workflow from draft to publication, ensuring reproducibility and transparency.

## Workflow

1. **Draft** → Develop manuscript (`notes.md`, `outline.md`, `abstract.md`, `references.bib`, `metadata.yml`).  
2. **Submitted** → Store submission files (`submission.md`, `cover_letter.md`, `response_to_reviewers.md`).  
3. **Accepted** → Archive accepted version.  
4. **Published** → Add publisher PDF, citation, and supplementary materials.  
5. **Registry** → Update `publications.md` and `citations.md` for tracking and citation consistency.
