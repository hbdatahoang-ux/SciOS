# SciOS Legal Documentation

Version: 1.0

Project: SciOS (Scientific Cognitive Operating System)

---

# Overview

The `docs/legal/` directory contains the legal, licensing, intellectual
property, and compliance documentation for the SciOS Research Platform.

These documents define how SciOS software, documentation, scientific
artifacts, datasets, models, and research outputs may be used,
distributed, cited, and contributed.

This directory complements the root-level `LICENSE`, `NOTICE`, and
`COPYRIGHT` files.

# Legal Hierarchy

If conflicts occur, documents take precedence in the following order:

1. LICENSE
2. NOTICE
3. COPYRIGHT
4. licensing.md
5. Individual artifact metadata
6. File headers

---

# Maintenance

All legal documents should be reviewed whenever:

- A new dependency is added.
- A new license is introduced.
- A research artifact has special licensing terms.
- A new publication is released.
- A major project version is published.
