# Privacy Policy

**SciOS – Scientific Cognitive Operating System**

Version: 1.0  
Status: Draft  
Last Updated: 2026-07-09

---

# Overview

SciOS is an open research platform for scientific computing,
autonomous reasoning, and reproducible research.

This document describes the privacy principles adopted by the
SciOS project for source code, documentation, research artifacts,
community participation, and optional cloud services.

---

# Privacy Principles

SciOS is designed around the following principles:

- Privacy by Design
- Data Minimization
- Transparency
- User Control
- Reproducibility
- Security by Default

Whenever possible, SciOS processes information locally.

---

# Information Collected

The SciOS source code repository does not intentionally collect
personal information.

Information may be voluntarily provided through:

- GitHub Issues
- Pull Requests
- Discussions
- Email communication
- Community forums
- Documentation contributions

Examples include:

- Name
- GitHub username
- Email address
- Affiliation
- Submitted source code
- Submitted documentation

---

# Scientific Data

SciOS may process scientific datasets supplied by users.

Examples include:

- experimental measurements
- simulation outputs
- benchmark datasets
- laboratory metadata
- computational workflows

Users remain responsible for ensuring that they have the legal
right to use and share these datasets.

---

# Research Artifacts

Research artifacts stored inside SciOS repositories may include:

- figures
- tables
- equations
- datasets
- notebooks
- workflows
- benchmark results
- supplementary materials

These artifacts are intended for scientific reproducibility.

---

# Personal Information

SciOS does not require personal information for:

- reading documentation
- cloning repositories
- inspecting source code
- building software locally

Personal information should never be committed into the repository.

Examples:

- passwords
- API keys
- authentication tokens
- private certificates
- unpublished personal information

---

# Cookies

The SciOS project itself does not use cookies.

Third-party services (such as GitHub or documentation hosting)
may use cookies according to their own privacy policies.

---

# Analytics

SciOS does not include mandatory telemetry.

If optional analytics modules are introduced, they should:

- be disabled by default
- clearly document collected data
- allow user opt-out

---

# Logging

Runtime logs should avoid storing sensitive information.

Recommended logging:

- timestamps
- module names
- execution status
- error identifiers

Avoid logging:

- passwords
- authentication tokens
- personal identifiers
- confidential datasets

---

# Security

Project maintainers make reasonable efforts to protect:

- repository integrity
- contributor information
- release artifacts
- documentation

Security vulnerabilities should be reported responsibly.

See:

```
SECURITY.md
```

---

# Third-Party Services

SciOS may integrate with external services such as:

- GitHub
- package repositories
- cloud providers
- artifact registries
- documentation hosting

Each service maintains its own privacy policy.

---

# International Data Transfers

Contributors may participate from multiple countries.

Repository hosting and collaboration platforms may process data
internationally.

Users should consult the privacy policies of those platforms.

---

# Data Retention

Repository history is maintained through Git.

Submitted commits generally remain permanently available unless
rewritten or removed according to project governance.

---

# Contributor Responsibilities

Contributors should:

- avoid uploading sensitive information
- anonymize research participants when necessary
- comply with applicable regulations
- respect institutional policies

---

# Compliance

SciOS aims to support compliance with applicable regulations,
including where relevant:

- GDPR
- local privacy regulations
- institutional research ethics
- publisher policies

Compliance remains the responsibility of users and institutions
deploying SciOS.

---

# Children's Privacy

SciOS is intended for researchers, developers,
students, and organizations.

It is not specifically directed toward children.
