# SciOS Paper Repository

This directory contains all core files and artifacts for the **SciOS** research paper.  
It follows the standardized structure used across all papers in the SciOS research program.

---

## Core Files

- **README.md** → Overview of the paper repository
- **metadata.yml** → Metadata (ID, version, status, author, related artifacts)
- **paper.md** → Main manuscript draft
- **abstract.md** → Abstract text
- **outline.md** → Paper outline
- **notes.md** → Research Notebook (lab notebook, daily research notes)
- **roadmap.md** → Paper roadmap (phases, planning)
- **milestones.md** → Milestone tracking
- **changelog.md** → Change history
- **todo.md** → Action items / backlog
- **references.bib** → Bibliography

---

## Artifact Directories

- **figures/** → Figures (with registry.csv)
- **tables/** → Tables (with registry.csv)
- **equations/** → Equations (with registry.csv)
- **supplementary/** → Supplementary materials (derivations, extended methods, results, raw images, videos, appendices, templates)
- **datasets/** → Raw, processed, and external datasets
- **scripts/** → Analysis and generation scripts
- **notebooks/** → Jupyter notebooks (exploratory, validation)
- **review/** → Reviewer notes, responses, revision history

---

## Usage Guidelines

- Keep all artifacts atomic and registered in their respective `registry.csv`.
- Use `metadata.yml` to ensure consistency across files.
- Separate **research notes** (`notes.md`) from **project management** (`roadmap.md`, `milestones.md`, `changelog.md`, `todo.md`).
- Follow the same template across all papers (CEIT, SciOS, QTC, MUSES).
