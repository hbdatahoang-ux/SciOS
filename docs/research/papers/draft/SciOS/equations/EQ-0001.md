## Title
Logistic Regression Hypothesis Function

---

## Overview
This equation defines the hypothesis function used in logistic regression, a fundamental model for binary classification tasks.

---

## Equation


\[
h_\theta(x) = \frac{1}{1 + e^{-\theta^T x}}
\]



---

## Description
- \( h_\theta(x) \): predicted probability that output = 1 given input \( x \).  
- \( \theta \): parameter vector (weights).  
- \( x \): input feature vector.  
- The function maps any real-valued input into the range (0,1), suitable for probability interpretation.
