# CEIT Project — Constrained-Induced Elasticity Theory

This folder contains all materials related to the CEIT Adaptive Control project, including notes, figures, datasets, benchmarks, experiments, methods, analysis, and code.

---

## Structure

- **notes.md** → Internal research notes, meeting logs, brainstorming, decisions, action items.  
- **figures/** → Core and supplementary figures.  
  - `figures.md` → Catalog of all figures with captions and status.  
  - `supplementary/` → SI-3 to SI-6 figures and derivations.  
  - `supplementary.md` → Catalog of supplementary materials.  
- **datasets.md** → Registry of datasets (experimental, synthetic, resampled).  
- **benchmarks.md** → Quantitative performance metrics (χ²_red, BIC, reproducibility).  
- **experiments.md** → Planned and executed experiments (E-0001, …).  
- **methods.md** → Detailed protocols for fabrication, imaging, modeling.  
- **analysis.md** → Data analysis pipeline (preprocessing → statistical tests → visualization).  
- **code_checklist.md** → Scripts and notebooks linked to SI-3 to SI-6.  
- **integration.md** → Map of how all components connect into a unified workflow.  

---

## Workflow Overview

1. **Methods** → Define protocols.  
2. **Experiments** → Generate raw data (planned/in progress).  
3. **Datasets** → Store processed data.  
4. **Analysis** → Run statistical tests.  
5. **Benchmarks** → Validate models.  
6. **Figures & Supplementary** → Visualize results.  
7. **Notes & Roadmap** → Track progress.  
8. **Code Checklist** → Ensure reproducibility.  
9. **Publications & Citations** → Finalize outputs.  

---

## Governance

- Weekly sync meetings logged in `notes.md`.  
- Major decisions require approval from SciOS Research Committee.  
- All updates merged into main branch after validation.
