This document serves as the table of contents for the CEIT Adaptive Control project.  
It provides quick access to all components.

## Usage
- Start with **Notes** and **ROADMAP** for current progress.  
- Use **Registry** to track IDs across datasets, benchmarks, experiments, publications, and citations.  
- Refer to **Integration** for workflow overview.  
- Consult **Governance** for decision-making and approval process.
