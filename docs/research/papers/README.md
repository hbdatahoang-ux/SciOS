# Paper Management Overview

This directory contains all research papers developed under the SciOS Research Platform.  
It is organized by lifecycle stages: **Draft → Submitted → Accepted → Published**.

---

## Directory Structure

docs/research/papers/
├── draft/          # Early-stage manuscripts, outlines, abstracts, notes
├── submitted/      # Papers submitted to journals/conferences
├── accepted/       # Papers accepted for publication
├── published/      # Final published versions with DOI and citation
├── publications.md # Global registry of all papers
├── citations.md    # Centralized citation strings (plain text + BibTeX)
└── README.md       # Overview of paper management system

Code

---

## Lifecycle Stages

- **[Draft](ca://s?q=Show_draft_papers)**: Contains outlines, abstracts, references, notes, and metadata for papers in preparation.  
- **[Submitted](ca://s?q=Show_submitted_papers)**: Contains cover letters, response to reviewers, submission records, and metadata.  
- **[Accepted](ca://s?q=Show_accepted_papers)**: Contains acceptance letters, camera-ready versions, copyright agreements, and metadata.  
- **[Published](ca://s?q=Show_published_papers)**: Contains final published versions, supplementary materials, citation files, and metadata.  

---

## Registries

- **[Publications](ca://s?q=Explain_publications.md)**: Tracks all papers across their lifecycle.  
- **[Citations](ca://s?q=Explain_citations.md)**: Centralized citation strings in plain text and BibTeX.  
- **INDEX.md (Published)**: Lists all published papers with DOI and citation.  
- **CITATION.cff**: GitHub citation file for repository-level citation.  

---

## Notes
- Each paper has a unique **ID** (e.g., P-0001) for tracking.  
- Metadata (`metadata.yml`) is maintained at every stage.  
- Supplementary materials include datasets, code, and reproducibility checklists.  
- All citations are synchronized across `citations.md`, `publications.md`, and `CITATION.cff`.
