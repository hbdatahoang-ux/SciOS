## Versioning Policy

SciOS uses Semantic Versioning:

```
MAJOR.MINOR.PATCH

Example:

0.1.0
0.2.0
1.0.0
```

Where

- MAJOR → incompatible architecture changes
- MINOR → new features
- PATCH → bug fixes and documentation updates
